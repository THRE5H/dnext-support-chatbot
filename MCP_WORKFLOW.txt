QUICK COMMANDS
════════════════════════════════════════════════════════════════════════════════

Local Development:
  $ cd backend && python main.py                    # Start backend
  $ cd backend/mcp_spec_server && python http_server.py  # Start MCP
  $ python backend/mcp_spec_server/test_mcp.py           # Test
  $ curl http://localhost:8001/health              # Health check

GitHub & Railway:
  $ git add . && git commit -m "msg" && git push    # Push to GitHub
  $ railway logs -s mcp-server                      # View logs on Railway
  $ railway open                                    # Open Railway dashboard

Testing Production:
  $ curl https://xxxx.up.railway.app/health         # Health check
  $ curl -X POST https://xxxx.up.railway.app/mcp ... # Query endpoint
