COMMON ISSUES
────────────────────────────────────────────────────────────────────────────

Q: Backend shows "error initializing database"
A: Delete data/chatbot.db and restart. It will recreate.

Q: Tests still show suspended account error
A: Make sure you pulled the latest code (git pull origin main)

Q: Port 8000 or 8001 already in use
A: Kill existing Python process or use different port:
   python main.py --port 9000
   python http_server.py --port 9001
